# MaiBot 插件接口能力总结

> 生成日期: 2026-01-13
> 项目版本: MaiBot 0.12.2

---

## 一、插件系统概述

MaiBot 插件系统基于组件化架构，支持四种核心组件类型，提供丰富的 API 接口供插件调用。

---

## 二、核心组件类型

### 1. Action 组件

**作用**: 处理聊天中的动作逻辑，由 Planner 规划后执行

**基类**: `BaseAction`

**核心属性**:
- `action_name`: 动作名称
- `action_description`: 动作描述
- `action_parameters`: 动作参数定义
- `action_require`: 动作使用条件说明
- `activation_type`: 激活类型
- `activation_keywords`: 关键词列表（KEYWORD 激活时使用）
- `random_activation_probability`: 随机激活概率（RANDOM 激活时使用）
- `parallel_action`: 是否允许并行执行

**激活类型**:
- `ALWAYS`: 默认参与到 planner
- `RANDOM`: 随机启用 action 到 planner
- `KEYWORD`: 关键词触发启用 action 到 planner
- `NEVER`: 从不激活

**核心方法**:
```python
async def execute(self) -> Tuple[bool, str]:
    """执行动作，返回(是否成功, 回复文本)"""
    pass
```

**便捷方法**:
- `send_text()`: 发送文本消息
- `send_image()`: 发送图片
- `send_emoji()`: 发送表情包
- `send_voice()`: 发送语音
- `send_command()`: 发送命令
- `send_hybrid()`: 发送混合类型消息
- `send_forward()`: 发送转发消息
- `send_custom()`: 发送自定义类型消息
- `store_action_info()`: 存储动作信息到数据库
- `wait_for_new_message()`: 等待新消息
- `get_config()`: 获取插件配置

**便捷属性**:
- `chat_stream`: 聊天流对象
- `chat_id`: 聊天ID
- `platform`: 平台
- `group_id`: 群ID
- `group_name`: 群名称
- `user_id`: 用户ID
- `user_nickname`: 用户昵称
- `is_group`: 是否群聊
- `target_id`: 目标ID

---

### 2. Command 组件

**作用**: 处理用户命令请求

**基类**: `BaseCommand`

**核心属性**:
- `command_name`: 命令名称
- `command_description`: 命令描述
- `command_pattern`: 命令匹配正则表达式

**核心方法**:
```python
async def execute(self) -> Tuple[bool, Optional[str], int]:
    """
    执行命令
    返回: (是否成功, 回复消息, 拦截力度)
    拦截力度: 0=不拦截, 1=不触发回复(replyer可见), 2=不触发回复(replyer不可见)
    """
    pass
```

**便捷方法**: 与 Action 相同的消息发送方法

---

### 3. EventHandler 组件

**作用**: 响应系统事件

**基类**: `BaseEventHandler`

**核心属性**:
- `event_type`: 事件类型
- `handler_name`: 处理器名称
- `handler_description`: 处理器描述
- `weight`: 处理器权重（决定执行顺序）
- `intercept_message`: 是否拦截消息

**事件类型**:
- `ON_START`: 启动事件
- `ON_STOP`: 停止事件
- `ON_MESSAGE_PRE_PROCESS`: 消息预处理
- `ON_MESSAGE`: 消息事件
- `ON_PLAN`: 计划事件
- `POST_LLM`: LLM 调用后
- `AFTER_LLM`: LLM 调用后（异步）
- `POST_SEND_PRE_PROCESS`: 发送前预处理
- `POST_SEND`: 发送后
- `AFTER_SEND`: 发送后（异步）

**核心方法**:
```python
async def execute(
    self, message: MaiMessages | None
) -> Tuple[bool, bool, Optional[str], Optional[CustomEventHandlerResult], Optional[MaiMessages]]:
    """
    执行事件处理
    返回: (是否成功, 是否继续处理, 回复消息, 自定义结果, 修改后消息)
    """
    pass
```

**便捷方法**: 与 Action 相同的消息发送方法

---

### 4. Tool 组件

**作用**: 工具组件，可供 LLM 调用或插件直接调用

**基类**: `BaseTool`

**核心属性**:
- `name`: 工具名称
- `description`: 工具描述
- `parameters`: 参数定义列表
  - 格式: `[("param_name", param_type, "description", required, enum_values)]`
- `available_for_llm`: 是否可供 LLM 使用

**核心方法**:
```python
async def execute(self, function_args: dict[str, Any]) -> dict[str, Any]:
    """执行工具（供 LLM 调用）"""
    pass

async def direct_execute(self, **function_args: dict[str, Any]) -> dict[str, Any]:
    """直接执行工具（供插件调用）"""
    pass
```

**参数类型**:
- `ToolParamType.STRING`: 字符串
- `ToolParamType.INTEGER`: 整数
- `ToolParamType.FLOAT`: 浮点数
- `ToolParamType.BOOLEAN`: 布尔值
- `ToolParamType.ARRAY`: 数组
- `ToolParamType.OBJECT`: 对象

## 三、API 能力列表

### 1. chat_api - 聊天管理 API

**功能**: 查询和管理聊天流信息

**主要方法**:
- `get_all_streams(platform)`: 获取所有聊天流
- `get_group_streams(platform)`: 获取所有群聊流
- `get_private_streams(platform)`: 获取所有私聊流
- `get_group_stream_by_group_id(group_id, platform)`: 根据群ID获取聊天流
- `get_private_stream_by_user_id(user_id, platform)`: 根据用户ID获取私聊流
- `get_stream_type(chat_stream)`: 获取聊天流类型
- `get_stream_info(chat_stream)`: 获取聊天流详细信息
- `get_streams_summary()`: 获取聊天流统计摘要

---

### 2. database_api - 数据库 API

**功能**: 数据库操作

**主要方法**:
- `db_query(model_class, query_type, filters, limit, order_by)`: 通用数据库查询
  - `query_type`: "get", "create", "update", "delete", "count"
- `db_save(model_class, data, key_field, key_value)`: 保存数据（创建或更新）
- `db_get(model_class, filters, limit, order_by)`: 获取数据
- `store_action_info(...)`: 存储动作信息

---

### 3. person_api - 个人信息 API

**功能**: 查询用户个人信息

**主要方法**:
- `get_person_id(platform, user_id)`: 根据平台和用户ID获取 person_id
- `get_person_value(person_id, field_name, default)`: 获取用户字段值
- `get_person_id_by_name(person_name)`: 根据用户名获取 person_id

---

### 4. llm_api - LLM 模型 API

**功能**: 调用 LLM 模型生成内容

**主要方法**:
- `get_available_models()`: 获取所有可用模型配置
- `generate_with_model(prompt, model_config, temperature, max_tokens)`: 使用模型生成内容
- `generate_with_model_with_tools(prompt, model_config, tool_options, ...)`: 使用模型和工具生成内容
- `generate_with_model_with_tools_by_message_factory(message_factory, ...)`: 通过消息工厂生成内容

---

### 5. send_api - 消息发送 API

**功能**: 发送各种类型的消息

**主要方法**:
- `text_to_stream(text, stream_id, typing, set_reply, reply_message)`: 发送文本
- `image_to_stream(image_base64, stream_id, ...)`: 发送图片
- `emoji_to_stream(emoji_base64, stream_id, ...)`: 发送表情包
- `command_to_stream(command, stream_id, ...)`: 发送命令
- `custom_to_stream(message_type, content, stream_id, ...)`: 发送自定义消息
- `custom_reply_set_to_stream(reply_set, stream_id, ...)`: 发送混合消息集
- `voice_to_stream(audio_base64, stream_id)`: 发送语音

---

### 6. message_api - 消息查询 API

**功能**: 查询和格式化消息

**主要方法**:
- `get_messages_by_time(start_time, end_time, limit, filter_mai)`: 获取时间范围内的消息
- `get_messages_by_time_in_chat(chat_id, start_time, end_time, ...)`: 获取指定聊天的消息
- `get_messages_by_time_in_chat_for_users(chat_id, start_time, end_time, person_ids, ...)`: 获取指定用户的消息
- `get_random_chat_messages(start_time, end_time, ...)`: 随机选择聊天的消息
- `get_messages_before_time(timestamp, ...)`: 获取指定时间之前的消息
- `get_recent_messages(chat_id, hours, ...)`: 获取最近的消息
- `count_new_messages(chat_id, start_time, end_time)`: 计算新消息数量
- `build_readable_messages_to_str(messages, ...)`: 将消息构建为可读字符串
- `build_readable_messages_with_details(messages, ...)`: 构建可读消息并返回详细信息
- `get_person_ids_from_messages(messages)`: 从消息中提取用户ID列表
- `filter_mai_messages(messages)`: 过滤机器人消息
- `translate_pid_to_description(pid)`: 将图片ID转换为描述

---

### 7. tool_api - 工具 API

**功能**: 获取工具实例和定义

**主要方法**:
- `get_tool_instance(tool_name, chat_stream)`: 获取工具实例
- `get_llm_available_tool_definitions()`: 获取 LLM 可用的工具定义列表

---

### 8. emoji_api - 表情管理 API

**功能**: 表情包管理

**主要方法**:
- `get_random(count)`: 获取随机表情包
- `search(keyword)`: 搜索表情包
- `add_emoji(...)`: 添加表情包
- `delete_emoji(...)`: 删除表情包

---

### 9. config_api - 配置管理 API

**功能**: 管理插件配置

**主要方法**:
- `get_plugin_config(plugin_name)`: 获取插件配置
- `set_plugin_config(plugin_name, config)`: 设置插件配置
- `get_config_schema(plugin_name)`: 获取配置 Schema

---

### 10. generator_api - 回复生成 API

**功能**: 生成回复内容

**主要方法**:
- `generate_reply(chat_stream, reply_reason, ...)`: 生成回复

---

### 11. component_manage_api - 组件管理 API

**功能**: 管理插件组件

**主要方法**:
- `enable_component(component_name)`: 启用组件
- `disable_component(component_name)`: 禁用组件
- `get_component_status(component_name)`: 获取组件状态

---

### 12. plugin_manage_api - 插件管理 API

**功能**: 管理插件

**主要方法**:
- `enable_plugin(plugin_name)`: 启用插件
- `disable_plugin(plugin_name)`: 禁用插件
- `reload_plugin(plugin_name)`: 重载插件
- `get_plugin_info(plugin_name)`: 获取插件信息
- `list_plugins()`: 列出所有插件

---

### 13. frequency_api - 频率控制 API

**功能**: 控制发言频率

**主要方法**:
- `get_talk_value(chat_id)`: 获取发言频率值
- `set_talk_value(chat_id, value)`: 设置发言频率值

## 四、插件开发流程

### 1. 创建插件目录结构
```
my_plugin/
├── _manifest.json          # 插件清单（必需）
├── plugin.py               # 插件主文件（必需）
├── requirements.txt        # 依赖配置（必需）
├── i18n/                   # 国际化文件（可选）
└── assets/                 # 资源文件（可选）
```

### 2. 定义插件清单 (_manifest.json)
```json
{
    "manifest_version": "1.0.0",
    "name": "plugin_name",
    "version": "1.0.0",
    "description": "插件描述",
    "author": "作者",
    "license": "MIT",
    "host_application": "MaiBot",
    "keywords": ["关键词1", "关键词2"],
    "categories": ["分类"],
    "plugin_info": {
        "components": [...]
    }
}
```

### 3. 实现组件类
- 继承对应的基类（BaseAction, BaseCommand, BaseEventHandler, BaseTool）
- 实现必需的抽象方法
- 定义组件信息类属性

### 4. 注册插件
```python
from src.plugin_system import BasePlugin, register_plugin

@register_plugin
class MyPlugin(BasePlugin):
    plugin_name = "my_plugin"
    version = "1.0.0"
    description = "插件描述"
    author = "作者"

    def get_plugin_components(self):
        return [
            (ActionInfo, ActionClass),
            (CommandInfo, CommandClass),
            (EventHandlerInfo, EventHandlerClass),
            (ToolInfo, ToolClass),
        ]
```

## 七、事件系统

### 1. 事件触发时机
- `ON_START`: 系统启动时
- `ON_STOP`: 系统停止时
- `ON_MESSAGE_PRE_PROCESS`: 消息预处理阶段
- `ON_MESSAGE`: 消息接收后
- `ON_PLAN`: 动作规划前
- `POST_LLM`: LLM 调用后
- `AFTER_LLM`: LLM 调用后（异步）
- `POST_SEND_PRE_PROCESS`: 消息发送前
- `POST_SEND`: 消息发送后
- `AFTER_SEND`: 消息发送后（异步）

### 2. 事件处理器优先级
- 通过 `weight` 属性控制执行顺序
- 权重越高，优先级越高

### 3. 消息拦截
- 通过 `intercept_message` 属性控制
- 拦截后可阻止后续处理

## 十、总结

MaiBot 插件系统提供了:
- **4 种核心组件类型**: Action, Command, EventHandler, Tool
- **13 个 API 模块**: 涵盖聊天、数据库、LLM、消息发送、工具等各个方面
- **丰富的便捷方法**: 简化常见操作
- **灵活的配置系统**: 支持插件自定义配置
- **强大的事件系统**: 支持在各个阶段介入系统流程
- **多种消息类型**: 支持文本、图片、表情、语音、混合、转发等

开发者可以基于这些接口开发功能丰富的插件，扩展 MaiBot 的能力。
