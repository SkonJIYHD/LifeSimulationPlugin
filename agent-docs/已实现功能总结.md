## 一、核心系统架构

### 1. 双进程架构
- **Runner 进程**: 守护进程，负责启动和监控 Worker 进程
- **Worker 进程**: 实际运行 MaiCore 的进程
- **重启机制**: 退出码 42 表示重启请求
- **优雅关闭**: 支持 Ctrl+C 信号

### 2. 入口程序
- 文件: `bot.py`
- 启动命令:
  - `python bot.py`: 正常启动
  - `python bot.py --test`: 测试模式
  - `python bot.py --test-with-ui`: 带 UI 测试模式

## 三、聊天系统

### 1. 消息处理流程
```
消息接收 → 消息预处理 → 事件处理(ON_MESSAGE)
  → Planner规划Action → Action执行 → 回复生成 → 后处理
  → 事件处理(POST_LLM, POST_SEND) → 消息发送
```

### 2. 核心模块
- `brain_chat/`: 大脑聊天系统
  - `planner.py`: Action 规划器
  - `action_executor.py`: Action 执行器
- `message_receive/`: 消息接收处理
- `replyer/`: 回复生成器
- `emoji_system/`: 表情包系统
- `knowledge/`: 知识库系统 (LPMM)
- `heart_flow/`: 心流系统

### 3. Action 系统
- **激活类型**: ALWAYS, RANDOM, KEYWORD, NEVER
- **Action 类型**:
  - reply: 回复动作
  - no_reply: 保持沉默
  - 自定义 Action
- **Action 参数**: 支持自定义参数传递
- **Action 要求**: 定义使用条件说明
- **并行执行**: 支持多个 Action 并行执行
- **Action 记录**: 存储到数据库供后续回忆

### 4. Planner 系统
- **Planner 平滑**: 控制规划器负荷
- **动态规划**: 根据上下文选择合适的 Action
- **Plan/Reply 日志**: 记录规划和回复过程
- **think_level**: 支持轻量/深度/动态思考模式

### 5. 回复生成
- **LLM 生成**: 使用大语言模型生成回复
- **表达风格**: 支持多种表达风格
- **引用回复**: 支持 LLM 控制是否引用消息
- **中文纠错**: 自动纠正常见中文错误
- **后处理**: 回复后处理流程

### 6. 消息发送
- **消息类型**: 文本、图片、表情、语音、命令、混合、转发
- **发送控制**:
  - 打字时间模拟
  - 回复消息引用
  - 消息存储控制
- **混合消息**: 支持多种消息类型组合发送
- **转发消息**: 支持合并转发

## 二十四、总结

MaiBot 作为一个功能丰富的拟人化 QQ 群聊 AI 机器人，已经实现了以下核心功能:

1. **完整的插件系统**: 支持 Action、Command、EventHandler、Tool 四种组件
2. **强大的聊天系统**: 消息接收、处理、回复全流程
3. **智能的规划系统**: Planner 自动规划合适的 Action
4. **灵活的记忆系统**: 长期/短期记忆、聊天历史
5. **丰富的知识库**: LPMM 知识库支持
6. **多样的表达系统**: 表情、表达学习、黑话系统
7. **完善的心流系统**: 动态发言频率控制
8. **灵活的人格系统**: 多风格、状态切换
9. **全面的 WebUI**: 完整的管理界面
10. **强大的 LLM 集成**: 多模型支持、工具调用
11. **完善的配置系统**: 动态配置、版本管理
12. **健全的日志系统**: 结构化日志、实时查看

这些功能共同构成了一个功能完整、架构清晰、易于扩展的 AI 机器人系统。
