## 项目概述

MaiBot 是一个基于大语言模型(LLM)的拟人化QQ群聊AI机器人，具有以下核心特性：

- **拟人化交互**: 通过人格配置和关系系统实现自然对话
- **插件系统**: 支持动态加载的插件架构
- **记忆系统**: 长期记忆和短期记忆管理
- **知识库**: LPMM(Large Personal Memory Model)知识库支持
- **心流系统**: 智能的对话节奏控制
- **WebUI**: 提供Web管理界面进行配置和监控

## 核心模块详解

### 1. 入口程序 (bot.py)

**架构**: 双进程架构

- **Runner进程**: 守护进程，负责启动和监控Worker进程
- **Worker进程**: 实际运行MaiCore的进程

**重启机制**:
- 退出码 `42` 表示重启请求
- 支持 `Ctrl+C` 信号优雅关闭

**启动命令**:
```bash
python bot.py [--test] [--test-with-ui]
```

### 3. 插件系统 (src/plugin_system/)

**组件类型**:

| 组件类型 | 作用 | 基类 |
|----------|------|------|
| Action | 动作组件，处理聊天中的动作逻辑 | `BaseAction` |
| Command | 命令组件，处理用户命令 | `BaseCommand` |
| EventHandler | 事件处理器，响应系统事件 | `BaseEventHandler` |
| Tool | 工具组件 | `BaseTool` |

**插件基类** (`base_plugin.py`):
```python
class BasePlugin:
    def get_plugin_components(self) -> List[...]:
        """获取插件包含的组件列表"""

    def register_plugin(self) -> bool:
        """注册插件及其所有组件"""
```

**插件清单** (`_manifest.json`):
```json
{
    "manifest_version": "1.0.0",
    "name": "plugin_name",
    "version": "1.0.0",
    "description": "插件描述",

    "host_application": "MaiBot",

```

**事件类型** (`events_manager.py`):
- `ON_START` / `ON_STOP` - 启动/停止事件
- `ON_MESSAGE` - 消息事件
- `ON_PLAN` - 计划事件
- `POST_LLM` / `AFTER_LLM` - LLM调用前后
- `POST_SEND` / `AFTER_SEND` - 发送消息前后

### 4. 聊天系统 (src/chat/)

**消息处理流程**:

```
消息接收 -> 消息预处理 -> 事件处理(ON_MESSAGE)
  -> Planner规划Action -> Action执行 -> 回复生成 -> 后处理
  -> 事件处理(POST_LLM, POST_SEND) -> 消息发送
```

**核心模块**:
- `brain_chat/` - 大脑聊天系统
  - `planner.py` - Action规划器
  - `action_executor.py` - Action执行器
- `message_receive/` - 消息接收处理
- `replyer/` - 回复生成器
- `emoji_system/` - 表情包系统
- `knowledge/` - 知识库系统(LPMM)
- `heart_flow/` - 心流系统

**Action基类** (`base_action.py`):
```python
class BaseAction:
    action_name: str

    async def send_forward(messages_list, ...)
    async def send_command(command_name, args, ...)
```

**Command基类** (`base_command.py`):
```python

    command_name: str
```

### 插件开发示例

#### 1. 创建Action组件

```python
# plugin.py
from typing import Tuple, Optional
from src.plugin_system import BaseAction, ActionActivationType, ComponentInfo

class ExampleAction(BaseAction):
    """示例Action组件"""

    action_name = "example"
    activation_type = ActionActivationType.KEYWORD
    activation_keywords = ["示例", "example"]

    @staticmethod
    def get_action_info() -> ComponentInfo:
        return ComponentInfo(
            name="example",
            description="这是一个示例动作",
            version="1.0.0",
            author="iFlow"
        )

    async def execute(self) -> Tuple[bool, str]:
        await self.send_text("这是一个示例动作!")
        return True, "动作执行成功"
```

#### 2. 创建Command组件

```python
from typing import Tuple, Optional
from src.plugin_system import BaseCommand, ComponentInfo

class HelloCommand(BaseCommand):
    """打招呼命令"""

    command_name = "hello"
    command_pattern = r"^/hello(?:\s+(?P<name>\w+))?$"

    @staticmethod
    def get_command_info() -> ComponentInfo:
        return ComponentInfo(
            name="hello",
            description="打招呼命令",
            version="1.0.0",
            author="iFlow"
        )

    async def execute(self) -> Tuple[bool, Optional[str], bool]:
        args = self.get_args()
        name = args.get("name", "世界")
        await self.send_text(f"你好, {name}!")
        return True, None, False
```

#### 3. 注册插件

```python
from src.plugin_system import BasePlugin, register_plugin
from typing import List, Type

@register_plugin
class MyPlugin(BasePlugin):
    """我的插件"""

    plugin_name = "my_plugin"
    version = "1.0.0"
    description = "这是一个示例插件"
    author = "iFlow"

    def get_plugin_components(self) -> List[Tuple[ComponentInfo, Type]]:
        return [
            (ExampleAction.get_action_info(), ExampleAction),
            (HelloCommand.get_command_info(), HelloCommand),
        ]
```

## 常见问题

### Q1: 配置文件不生效
确保配置文件在 `config/bot_config.toml`，且格式为有效的TOML。

### Q2: 插件无法加载
检查 `_manifest.json` 格式是否正确，插件类是否继承自 `BasePlugin`。

### Q3: LLM调用失败
检查 `model_config.json` 中的API密钥配置，确保网络连接正常。

### Q4: 消息发送失败
检查消息长度是否超过限制，格式是否正确。

## 二十五、LifeSimulationPlugin - 事件及人体模拟插件

### 插件信息
- **插件名称**: LifeSimulationPlugin
- **版本**: 1.6.0
- **作者**: GLM4.5 and Skon
- **许可证**: AGPL-3.0-or-later
- **主页**: https://github.com/SkonJIYHD/LifeSimulationPlugin
- **仓库**: https://github.com/SkonJIYHD/LifeSimulationPlugin
- **描述**: AI驱动的生活模拟：日程、事件、习惯、节日和情绪判断，实现拟人化行为

### 插件概述
LifeSimulationPlugin 是一个基于 AI 驱动的事件及人体模拟插件，让机器人具有真实人类的生理状态、日常活动、社交行为和环境感知能力，使机器人更加拟人化和生动。

### 核心特性
- 🤖 **AI 驱动的日程生成** - AI 根据人格、习惯和当前状态生成日程
- 🎲 **AI 驱动的随机事件生成** - AI 根据当前情境生成随机事件
- 🏥 **生病系统** - AI 多维度判断是否生病，生病后自动调整日程
- 💚 **健康状态由事件决定** - 健康状态由随机事件和日程决定
- 🎯 **习惯系统** - 习惯可以配置或由 AI 根据人格生成
- 🎉 **节日 API 集成** - 通过 API 动态获取节假日信息
- 😊 **AI 驱动的情绪判断** - AI 根据多方面因素判断情绪
- 📝 **可编辑的 AI 提示词** - 提示词在配置文件中，可自定义
- 💬 **AI 生成话语** - 所有对话由 AI 生成，不固定
- 🔒 **只读生理状态** - 生理状态数据不能通过命令修改
- ⏰ **自定义时间/日期 API** - 支持用户自定义时间日期获取方式
- 🔧 **可配置 AI 模型** - 支持 9 种模型配置类型
- 🛠️ **习惯工具** - LLM 可调用工具获取习惯信息
- 👥 **社交网络系统** - 记录用户关系，实现个性化社交行为
- 💕 **亲密度系统** - 通过互动积累和衰减机制管理亲密度
- 🔗 **关系管理** - 支持9种关系类型（陌生人、熟人、朋友、好友、挚友、家人、伴侣、敌人、拉黑）
- 🎯 **关系设置工具** - LLM 可调用工具设置用户关系类型，包括敌人和拉黑

### 配置系统
插件使用 TOML 格式的配置文件 `config.toml`，包含以下配置节：

#### [plugin] - 插件基础配置
- `config_version`: 配置文件版本
- `enabled`: 是否启用插件
- `update_interval`: 状态更新间隔（秒）
- `data_dir`: 数据目录

#### [ai] - AI模型配置
- `schedule_model`: 日程生成模型
- `event_model`: 随机事件生成模型
- `emotion_model`: 情绪判断模型
- `habit_model`: 习惯生成模型
- `temperature`: AI温度
- `max_tokens`: AI最大token数

#### [prompts] - AI提示词配置
- `schedule_generation`: 日程生成提示词
- `random_event_generation`: 随机事件生成提示词
- `emotion_judgment`: 情绪判断提示词
- `habit_generation`: 习惯生成提示词
- `social_network_analysis`: 社交网络分析提示词
- `intimacy_judgment`: 亲密度判断提示词

#### [habits] - 习惯配置
- `use_ai_generation`: 是否使用AI生成习惯

#### [schedule] - 日程配置
- `regenerate_daily`: 每天重新生成日程
- `random_event_probability`: 随机事件触发概率
- `illness_system_enabled`: 启用生病系统
- `illness_probability_multiplier`: 生病概率倍数
- `auto_regenerate_on_illness`: 生病时自动重新生成日程

#### [time_api] - 时间/日期API配置
- `method`: 时间获取方式（builtin/custom）
- `url`: 自定义时间API URL
- `timeout`: 请求超时（秒）
