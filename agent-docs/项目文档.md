## 项目概述

MaiBot 是一个基于大语言模型(LLM)的拟人化QQ群聊AI机器人，具有以下核心特性：

- **拟人化交互**: 通过人格配置和关系系统实现自然对话
- **插件系统**: 支持动态加载的插件架构
- **记忆系统**: 长期记忆和短期记忆管理
- **知识库**: LPMM(Large Personal Memory Model)知识库支持
- **心流系统**: 智能的对话节奏控制
- **WebUI**: 提供Web管理界面进行配置和监控

from typing import Tuple, Optional
from src.plugin_system import BaseAction, ActionActivationType, ComponentInfo

class ExampleAction(BaseAction):
    """示例Action组件"""

    action_name = "example"
    activation_type = ActionActivationType.KEYWORD
    activation_keywords = ["示例", "example"]

    @staticmethod
    def get_action_info() -> ComponentInfo:
        return ComponentInfo(
            name="example",
            description="这是一个示例动作",
            version="1.0.0",
            author="iFlow"
        )

    async def execute(self) -> Tuple[bool, str]:

#### 2. 创建Command组件

```python
from typing import Tuple, Optional
from src.plugin_system import BaseCommand, ComponentInfo

class HelloCommand(BaseCommand):
    """打招呼命令"""

    command_name = "hello"
    command_pattern = r"^/hello(?:\s+(?P<name>\w+))?$"

    @staticmethod
    def get_command_info() -> ComponentInfo:
        return ComponentInfo(
            name="hello",
            description="打招呼命令",
            version="1.0.0",
            author="iFlow"
        )

    async def execute(self) -> Tuple[bool, Optional[str], bool]:
        args = self.get_args()
        name = args.get("name", "世界")
        await self.send_text(f"你好, {name}!")
        return True, None, False
```

#### 3. 注册插件

## 常见问题

### Q1: 配置文件不生效
确保配置文件在 `config/bot_config.toml`，且格式为有效的TOML。

### Q2: 插件无法加载
检查 `_manifest.json` 格式是否正确，插件类是否继承自 `BasePlugin`。

### Q3: LLM调用失败
检查 `model_config.json` 中的API密钥配置，确保网络连接正常。

### Q4: 消息发送失败
检查消息长度是否超过限制，格式是否正确。
